## 二、2.3.7 的三项核心改动

### 1. 本地单人（内嵌服务器）

| 项 | 说明 |
|---|---|
| 入口 | 大厅 HERO 下方「本地单人」卡片 → 「启动本地单人」按钮 |
| 原理 | 客户端内置完整服务器（`resources/server-embedded`，59 MB），子进程跑 `start-local.mjs` |
| 端口 | 默认 3001，被占用自动找空闲端口 |
| 数据 | `<数据根>/local-server/` |
| 不依赖 | 完全不连线上服 |
| 退出 | `before-quit` 自动停子进程 |

**打包关键**：`package.json` 的 `build.extraResources` 把 `server-embedded` 拷到 `resources/server-embedded`（不进 asar）。

### 2. 中转站：不内置任何地址

| 项 | 说明 |
|---|---|
| `RELAY_PRESETS` | **`[]`（空）** —— 避免为特定站点背书/争议 |
| 用户输入 | 保存时写入 `relay.json` 的 `url` + `history`（最近优先、上限 8） |
| 快捷地址 | = 历史列表（去重、当前地址也列出） |
| 首次体验 | 快捷栏为空 + 提示「请先设置中转站地址」 |
| 占位符 | `https://relay.example.com`（通用示例，不含真实站点） |

⚠️ **代码里不得再出现任何真实中转站域名**（`wei.bbsmc.cn` / `game.rainya.me` / `game.xiaolubao.com`），注释也不许。

### 3. 表情包清单不缓存（修「客户端看不到新表情」）

| 项 | 说明 |
|---|---|
| 根因 | `index.json` 的 URL 不带 `~hash` → 拦截器 `matchesContentHash` 直接返回 `true` → **永远命中本机旧文件** |
| 连带坑 | 加「强制回源」后，写回代码被 `if (cpath && ...)` 包着，而清单 `cpath` 为 `null` → 拿到新清单却没写回 |
| 修法 | ① 清单不吃本机缓存 ② 不吃代理缓存 ③ 回源处理不依赖 `cpath` |

正则标记：`isRuntimeManifest = /\/assets\/local\/sp-community-emotes\/index\.json$/i`

## 三、内嵌服务器打包清单（59 MB / 1199 文件）

必须齐全，缺一个就 `boot-err`：

```
server-embedded/
├── server/            6.2 MB  服务端代码
├── shared/            0.7 MB  前后端共享
├── plugins/           0.1 MB
├── data/             32.9 MB  游戏数据（含 versions/ 14.3 MB）
├── packs/                    语言包索引
├── tools/             1.5 MB  studio 依赖的 atlas.mjs
├── node_modules/          .7 MB  **仅 ws + acorn**（服务端真正用到的）
├── start-local.mjs          本地单人专用入口（关掉 studio 热重载）
└── public/
    ├── index.html   5.1 KB   ⚠️ 必须
    ├── manifest.json         PWA
    ├── sw.js
    ├── announcement.json
    ├── js/           4 MB    ⚠️ 必须
    ├── css/          0.7 MB  ⚠️ 必须
    ├── vendor/       3.5 MB  ⚠️ **必须**（preact/htm/pixi——缺它必报 boot-err）
    ├── fonts/        0.2 MB  ⚠️ 必须
    ├── i18n/         0.7 MB
    ├── icons/
    ├── studio/       0.3 MB  （studio 模块加载期就 import，不能省）
    ├── admin/        0.1 MB
    └── dev/          7.5 MB  （顺手带上，非必需）
```

**不含 `public/assets/`（1 GB 游戏素材）** —— 由客户端本机素材库提供。

### 踩过的坑

```
第一次打包只拷了 js/css/i18n/icons → 缺 vendor/ → 游戏脚本加载失败
浏览器报：「游戏脚本加载失败，请检查网络连接后刷新页面」(boot-err)
```

**验收方法（必做）**：把 `index.html` 里所有 `src=` / `href=` 的本地路径逐个 fetch，必须全 200。
2.3.7 实测：**37 个引用资源全部 200**。

## 四、素材拦截器（`src/assets.js`）的判定链

```
请求 /assets/<rel>
 ① 本机素材库：算本机文件 SHA-256 前16 与 URL 的 ~hash 比
     ├ 一致 → 命中（0 网络）
     ├ 不一致 → 判过期，走 ③
     └ 无 ~hash（运行时清单）→ 强制走 ③
 ② 代理缓存（上次回源落盘）—— 运行时清单跳过
 ③ 回源服务器 → 成功则
     ├ 写回本机素材库（下次直接命中）
     └ 落代理缓存（清单除外）
```

**关键常量/规则**：

| 项 | 值 |
|---|---|
| 哈希算法 | SHA-256 前 16 位（**不是 SHA-1**，§11.5.3 坑） |
| 绑定表键 | `${serverHash}\|${相对路径}`（**必须带路径**，§11.5.5 坑） |
| Spine 模型 | skel+atlas+贴图 **共用一个模型聚合哈希**，客户端算不出 → 首次必须回源一次 |
| 条件请求 | 转发前剥掉 `If-None-Match/If-Modified-Since`；收到 304 用本机文件兜底（§11.5.6 坑） |
| 4xx | 不重试；连续失败 8 个 → 中止（§11.5.7） |
